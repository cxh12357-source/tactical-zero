# Human topology attribution

MakeHuman Community graphical assets, downloaded 2026-09-10. Only graphical data is used; no MakeHuman application source code.

- Base mesh: https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj
- License: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md (section C: assets, including the base mesh, CC0 1.0).
- Full asset statement preserved in LICENSE.ASSETS.md.

The Blender 0.12 remodeller uses facial and hand topology subsets, changes proportions and combines them with original Tactical Zero clothing and equipment. Portrait references are the existing project artwork.
